# STUDENT-ID-CARD-GENERATOR
A simple web app that creates a digital student ID card from a form, with photo upload and a print/save option.
# Student ID Card Generator

 Project Overview

The **Student ID Card Generator** is a web-based application that allows users to create student ID cards by entering their personal and academic details through a simple form.

The application uses HTML, CSS, and JavaScript to collect student information and display it in a properly designed ID card format.

The main aim of this project is to make student ID card creation easier, faster, and more convenient.

 Objectives

- To create a simple and user-friendly student ID card generator.
- To collect student details through an input form.
- To display the entered information in an ID card layout.
- To allow users to upload a student photograph.
- To practise front-end web development using HTML, CSS, and JavaScript.

 Features

- Student information input form.
- Student photograph upload.
- Dynamic ID card generation.
- Clean and user-friendly interface.
- Styled ID card layout.
- Easy-to-use functionality.

Technologies Used

- **HTML5** – Structure of the application.
- **CSS3** – Styling and layout.
- **JavaScript** – Dynamic functionality and ID card generation.

How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Enter the required student details.
5. Upload a photograph.
6. Generate and view the student ID card.
